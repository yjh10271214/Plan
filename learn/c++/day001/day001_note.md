## virtual function table

> - 包含虚函数的类在编译是都会生成一张属于自己的虚函数表,属于静态数据
> - 包含虚函数的类都有一个vptr(virtual table pointer)

## inherit

> - 子类继承构造是时，先分配一整块内存父类大小+自己独有的成员
> - this指针指向的是子类分配的内存，在构造父类的时候也是这个this指正，所以父类构造也是在子类分配的这块内存上，**先构造基类部分，在构造子类部分**

## polymorphism

> - **多态**
>   - 父类指针指向子类对象时，通过该对象的vptr找到子类的虚函数表，从而调用子类重写的虚函数
> - 本质查表，多态的动态绑定只对虚函数生效，非虚函数不走虚表，是静态绑定

## others

> - 空类大小会有一个字节，因为规定类必须有地址所以必须得分配内存才有地址
> - 虚函数代码存放在代码段，不在对象内存空间里, 对象里只有指向虚函数表的指针（vptr）*
> - 通过多态调用不能访问父类没有的虚函数受父类限制
> - **构造函数中调用虚函数无效**
>   - 在基类构造函数里调虚函数，只会调用基类自己的版本，因为此时vptr还指向基类虚表
> - **虚析构函数**
>   - 如果一个类可能会作为基类使用，并且我们需要通过基类指针去`delete`子类对象，基类的析构函数必须声明为`virtual`，否则子类析构函数不会被调用，造成内存泄漏
